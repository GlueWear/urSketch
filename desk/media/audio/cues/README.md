# Game cues

The nine MP3 files are the user-provided production audio. YourTurnToDraw
has the overlapping SomeoneElseGotTheWord reference subtracted without
cropping. The original and cleanup script/report are kept in the repository.

Cues are fetched from authenticated content-addressed media routes, decoded
on the first browser interaction, and routed through the game master volume
and selected output. TickingNoise is scheduled every 250 ms during the finish
window; theme-song controls do not affect game cues.
